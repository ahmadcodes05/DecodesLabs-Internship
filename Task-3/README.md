# Random Password Generator 🔐

This is Project 3 of my DecodeLabs Python Programming Internship (Batch 2026).

I created this project using Python to generate random passwords based on the length and character types selected by the user.

## Features

- Choose password length (4–128 characters)
- Include uppercase and lowercase letters
- Include numbers and special characters
- Ensure each selected character type appears at least once
- Handle invalid user input
- Use Python's `secrets` module for secure random generation

## Technologies Used

- Python
- `secrets` module
- `string` module

## How to Run

1. Open the project in PyCharm.
2. Open `password_generator.py`.
3. Right-click the file and select **Run**.
