# To-Do List Application

## Description
A command-line To-Do List application developed using Python during my DecodeLabs internship.

## Features
- Add tasks
- View tasks
- Mark tasks as completed
- Delete tasks
- Save tasks permanently using JSON

## Technologies Used
- Python
- JSON
- File Handling

## How to Run
1. Download or clone this repository.
2. Open the project in PyCharm.
3. Run the Python file.
4. Follow the menu options to manage your tasks.

## Skills Learned
- Python lists and dictionaries
- Loops and conditional statements
- Functions
- Exception handling
- JSON file storage
